# QuickPOS

QuickPOS is a simple and modern POS (Point of Sale) landing page built using PHP, HTML, and CSS.

## Features
- Responsive design
- Hero section with CTA button
- Features section (Inventory, Analytics, Integration)
- Pricing table
- Contact form with PHP validation

## Technologies Used
- HTML
- CSS
- PHP

## How to Run
1. Install XAMPP
2. Place project in htdocs folder
3. Run Apache server
4. Open: localhost/QuickPOS
